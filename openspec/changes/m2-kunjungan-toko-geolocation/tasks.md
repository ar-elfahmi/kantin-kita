## 8. Notes / known follow-ups

- Sidebar HTML is now duplicated in 4 places (dashboard-vendor inline, manage-menu inline, customer/_sidebar partial used by 7 views). The partial filename is misleading (it's no longer customer-specific). Rename to `vendor/_sidebar.blade.php` is the natural next refactor — deferred to keep this PR focused.
- Threshold is a `private const` on the controller for now. Per-vendor configurability would mean adding a column on `vendors` or a `vendor_settings` table.
- The visit-store endpoint trusts client-submitted `sales_accuracy`. A malicious client could send `sales_accuracy=10000` to inflate threshold_efektif. Acceptable academic-project trade-off; production would cap server-side (e.g., max 200m).
- `kunjungan_toko.user_id` is captured from the authenticated user. In current kantin-kita that's always the vendor user; the FK is `nullOnDelete` so the visit log survives if a vendor staff account is deleted later.
- Browser geolocation needs HTTPS or localhost; documented same as M3 NFC. Phones testing over LAN will need ngrok or chrome://inspect port-forwarding.
